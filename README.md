# Python Katas

A collection of 40 Python coding challenges completed as part of my software development training.

This repository showcases my practice with Python fundamentals, algorithmic problem-solving, data structures, functional programming, exception handling, and object-oriented programming.

## Learning Objectives

Through these challenges, I have practiced:

- Writing reusable functions and solving algorithmic problems.
- Working with Python's built-in data structures.
- Applying functional programming techniques.
- Implementing recursive solutions.
- Validating user input and handling exceptions.
- Designing classes and managing object state.
- Processing and transforming text and numerical data.

## Technologies & Concepts

- **Language:** Python 3
- **Data Structures:** Lists, tuples, dictionaries, and sets
- **Functional Programming:** `map()`, `filter()`, `reduce()`, and lambda expressions
- **Algorithms:** Searching, recursion, string manipulation, and mathematical operations
- **Error Handling:** Exception handling, input validation, and custom exceptions
- **Object-Oriented Programming:** Classes, attributes, methods, and object state

## Functional Programming

A significant part of this repository focuses on Python's functional programming tools.

| Function | Practical Applications |
|---|---|
| `map()` | Transforming collections and applying operations to multiple elements |
| `filter()` | Selecting elements based on conditions |
| `reduce()` | Accumulating values, calculating products, and combining elements |
| `lambda` | Defining short anonymous functions |

These exercises demonstrate different approaches to processing collections of data.

## Running the Exercises

**Requirements**

- Python 3

If the exercises are stored in `.py` files, run them from the terminal:

```bash
python filename.py
```

If they are stored in Jupyter notebooks (`.ipynb`), open them using Jupyter Notebook or Visual Studio Code with the Jupyter extension.

No external APIs or databases are required for the exercises described in this repository.
